Search Guide

이 화면은 무엇을 위한 페이지인가요?

하나의 검색창만 두기보다, 사용자가 검색 전후에 자주 확인하는 정보 흐름을 함께 정리해주는 시작 페이지 역할을 합니다.

검색은 어디로 연결되나요?

입력한 키워드는 네이버 또는 구글 검색으로 바로 이동할 수 있고, 화면 안에서는 관련 주제와 짧은 설명을 먼저 확인할 수 있습니다.

스타일 상담 기능은 어떤 방식으로 쓰나요?

키, 몸무게, 사진과 취향 메모를 입력하면 체형과 무드 기준의 간단한 스타일 보고서를 받아볼 수 있습니다. 현재 공개 사이트에서는 브라우저 안에서 바로 읽을 수 있는 요약 노트 형식으로 정리됩니다. 사용 예시는 출근룩 샘플, 데이트룩 샘플, 여행 캐주얼 샘플에서 확인할 수 있습니다.

자주 묻는 질문

FAQ

이 사이트는 무엇을 제공하나요?

검색 시작 화면, 생산성 위젯 구조, 정보 탐색 흐름, 운영 기준과 정책 문서를 함께 제공하는 정보형 포털입니다.

검색 결과는 외부 검색엔진을 직접 보여주나요?

아니요. 이 사이트는 검색 결과를 복제하지 않고, 검색으로 이어지기 전후에 도움이 되는 설명과 정리형 콘텐츠를 함께 제공합니다.

광고는 어떤 기준으로 운영하나요?

광고는 콘텐츠를 대체하지 않으며, 사용자가 읽어야 할 정보보다 먼저 보이도록 설계하지 않는 것을 원칙으로 합니다.

자세한 글은 어디서 읽을 수 있나요?

메인 가이드 카드나 가이드 모음 페이지에서 검색 설계, 스타일 상담, 환율 읽기 같은 상세 글을 확인할 수 있습니다.

운영 원칙

Site Standards
  • 독창적인 한국어 콘텐츠 유지 다른 사이트 문구를 복제하지 않고, 실제 사용 흐름에 맞춘 자체 설명과 안내를 작성합니다.
  • 명확한 탐색 구조 유지 서비스, 가이드, 검색결과, 운영원칙, 정책 페이지를 분리해 사용자가 원하는 정보를 쉽게 찾도록 설계합니다.
  • 광고보다 정보 우선 콘텐츠가 부족한 페이지를 수익화 수단으로 사용하지 않고, 정보 이해를 방해하는 과도한 광고 배치를 지양합니다.
